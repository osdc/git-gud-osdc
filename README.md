# GitGud - Website Repo

### Learn Git. Make Memes. Make Your First Contribution. 

<img src="https://raw.githubusercontent.com/kuwushagra/git-gud-osdc/refs/heads/main/screenshot.png"/>

> **Your first step into Open Source doesn't have to be scary. It can be a meme.**

**GitGud** was a beginner-friendly, hands-on workshop hosted by **[OSDC](https://osdc.dev)** that introduced students and newcomers to Git, GitHub, version control, and open-source collaboration through a shared meme project.

The workshop focused on learning by doing. Participants worked with Git and GitHub throughout the process and made their first contribution to an open-source project.

## How Participants GotGud
```
+----------------------+
|      Pick a Meme     |
+----------+-----------+
           |
           v
+----------------------+
|    Add Your Captions |
+----------+-----------+
           |
           v
+----------------------+
|     Commit Your Work |
+----------+-----------+
           |
           v
+----------------------+
|     Push to GitHub   |
+----------+-----------+
           |
           v
+----------------------+
|    Open a Pull       |
|      Request         |
+----------+-----------+
           |
           v
+----------------------+
|   First Contribution |
+----------------------+
```
---

## What Participants Learned

The workshop provided hands-on experience with the fundamentals of Git and GitHub, including:

- Git and GitHub
- Repositories and remotes
- Commits and tracking changes
- Branches
- Pull Requests
- The Git workflow
- Collaborative development
- Contributing to open-source projects

Participants also got to see how these concepts come together in a practical project workflow, from making a local change to submitting it as a Pull Request.
